# Para ti, mi amor 🌻
Una sorpresa de Edwin: semilla, árbol de girasoles y dos pingüinos que se abrazan.

Abrir `index.html` directamente, sin instalar nada. Compatible con computadora y celular. No necesita archivos externos ni conexión para la animación.

El contador empieza el 5 de agosto de 2025 a medianoche de El Salvador (UTC−6). Muestra días totales, horas, minutos y segundos; también años y meses completos. El mensaje celebra un año y dos meses.

## Publicar
Subir index.html y vercel.json a un repositorio de GitHub. En Vercel, importar ese repositorio, elegir Other como Framework Preset y dejar vacíos Build Command y Output Directory. Publicar con Deploy.

## Personalizar
Editar la constante `message` en index.html para cambiar la dedicatoria, y `START` para cambiar la fecha. El botón «Volver a ver» repite la animación.
